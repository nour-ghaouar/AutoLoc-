# Atelier 3 - Repository Notes

## Choix des interfaces Repository

Les repositories du projet AutoLoc utilisent JpaRepository<Entite, Long>.

JpaRepository permet notamment :
- les opérations CRUD ;
- la récupération des données sous forme de List ;
- le tri et la pagination ;
- les opérations spécifiques JPA.
